    Firmware sends one line per second: AQ,pm10s,pm25s,pm100s,pm10e,pm25e,pm100e,p03,p05,p10,p25,p50,p100.
    Cards & mass chart use the standard concentration.
    Web Serial / Web Bluetooth need Chrome or Edge (desktop). Bluetooth also works on Android Chrome.
    


    BLE connects but no data? Check the connection log above.
    If it says notifications started but no data arrives: the most common cause is that the board
    is still connected over USB to a serial monitor — close the Arduino Serial Monitor (and this app's
    USB connection) so the firmware loop isn't blocked, then reconnect over BLE. Also make sure only
    one app/tab is connected to the board's Bluetooth at a time (phone apps like nRF Connect / LightBlue
    will hold the connection and block the browser).
